# Jinyuan Zhang Portfolio

A static, bilingual portfolio website for storyboard, animation, visual development, and AI artwork.

## Pages

- `index.html` — Home and introduction
- `storyboard.html` — Rigged animation and Time Train projects, including their videos and storyboard images
- `visual.html` — Visual development
- `ai-art.html` — AI artwork
- `more.html` — Additional work and contact

The language toggle switches between English and Chinese. Shared styles are in `portfolio.css`; translations and language persistence are in `language.js`.

## Local preview

Serve this directory with any static web server and open its `index.html`. No build step is required.

## GitHub Pages

Publish the repository from its `main` branch and root directory in the repository's Pages settings. The site is static and includes a `.nojekyll` file.
